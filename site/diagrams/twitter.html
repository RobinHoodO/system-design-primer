Fan Out Service

What it is

A service that distributes a tweet to followers.

Its job here

It receives the new tweet from Write API, queries User Graph Service, writes follower timelines to Memory Cache, indexes search, and starts notifications.

Trade-off

Users with millions of followers can take minutes to finish fanout.

✕

1 · Post a tweet

The Write API stores a tweet, then the Fan Out Service builds followers’ home timelines, indexes search, stores media, and sends notifications.

The post path favors fast writes and fanout.

2 · View home timeline

Timeline Service reads timeline ids from Memory Cache, then multigets tweet and user information.

The home timeline favors fast reads.

3 · View user timeline

Read API retrieves the user’s own timeline from the SQL database.

This path reads the user’s stored tweets.

4 · Search keywords

Search API forwards a parsed query to Search Service, which queries the Search Cluster and returns ranked results.

The search path is read-heavy.
