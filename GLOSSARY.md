# Glossary — System Design Primer learning site

**Learning site**: The linked set of HTML pages built on top of this fork, in the look of the GTM hub. Every page, diagram and card can be reached by a link.

**Landing page**: The first page of the learning site. It has four tabs, like the GTM hub: Overview (with the hero diagram as the way in), Topics, Solutions and Diagrams.

**Topic page**: One page for one primer concept (for example Load balancer or Cache). It opens with a summary card, followed by the primer's original text, word for word.

**Sub-topic**: A section inside a topic page (for example Sharding inside Database). It has its own link, so other pages can jump straight to it.
_Avoid_: separate page per heading

**Solution page**: One page for one worked example from the primer's solutions (for example Design Twitter or Parking lot).

**Link table**: The one shared list of every topic, sub-topic, diagram box and solution, with the link that reaches it. All links on the site come from it.

**Back-link**: A link on a topic page to each place that points at it (for example "Shown in: Hero diagram, Design Twitter").

**Summary card**: A short plain-English card at the top of a topic page. It has the same parts as a diagram card: what it is, its job, and the trade-off.

**Original text**: The primer's own README prose and links, unchanged, under the summary card.
